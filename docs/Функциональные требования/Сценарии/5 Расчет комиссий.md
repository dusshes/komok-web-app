## Функциональные требования к расчету комиссий

### А. Для Клиента (При подаче заявки)
* Когда клиент в Личном кабинете заполняет форму «Продать вещь» и указывает «Желаемую цену» (сколько он хочет получить на руки), система в реальном времени с помощью JavaScript (или при сохранении на бэкенде) делает SQL-запрос к таблице `commission_rules` и вычисляет:
  1. Комиссию магазина.
  2. Итоговую цену, по которой товар будет выставлен на витрину (`Финальная цена = Желаемая цена + Комиссия`).
* Клиент должен сразу видеть прозрачный расчет перед отправкой заявки.

### Б. Для Администратора (При одобрении заявки)
* Во вкладке «Новые заявки» админ видит калькуляцию: `Цена клиента`, `Рассчитанная комиссия` и `Итоговая цена на витрину`.
* Админ может вручную изменить цену товара и комиссию.
