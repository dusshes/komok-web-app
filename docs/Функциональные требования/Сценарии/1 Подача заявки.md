Действие: Авторизованный клиент заходит в личный кабинет и заполняет форму «Заявка на размещение».

В базе данных: В таблице items создается новая запись. Полю user_id присваивается ID этого клиента, а поле status автоматически становится "На рассмотрении". 

На главную страницу (витрину) этот товар пока не попадает.
