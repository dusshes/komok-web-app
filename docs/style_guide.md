# Стайлгайд проекта "Комок"

Это руководство описывает стандарты оформления пользовательского интерфейса для обеспечения единообразия и адаптивности.

## 1. Общая структура (Layout)
- **Базовый шаблон:** Все страницы должны наследовать `app/templates/base.html`.
- **Контейнер:** Основной контент должен быть обернут в `<div class="container mt-4">`.
- **Отступы:** Использовать классы Bootstrap 5 для создания ритма:
  - `mt-4` для верхнего отступа контента.
  - `mb-5` для нижних отступов разделов.

## 2. Навигация
- **Navbar:** Использовать стиль `navbar-dark bg-dark`.
- **Элементы:** Ссылка на главную страницу (логотип "Комок") должна всегда быть в левой части.

## 3. Кнопки
- **Основные (призыв к действию):** `btn btn-primary`.
- **Второстепенные:** `btn btn-secondary`.
- **Опасные действия (удаление):** `btn btn-outline-danger`.

## 4. Формы
- **Поля ввода:** Обязательное использование класса `form-control`.
- **Группировка:** Каждое поле должно быть обернуто в `mb-3` для вертикального разделения.
- **Сохранение данных при ошибках:** При возникновении ошибок валидации или отправки формы введенные пользователем данные (кроме паролей) должны сохраняться в полях ввода, чтобы пользователю не приходилось заполнять форму заново.

## 5. Типографика
- Использовать стандартные заголовки `h1`-`h6` Bootstrap.
- Для текста использовать классы `text-muted` для второстепенной информации.

## 6. Карточки (UI-компоненты)
- При отображении объявлений использовать структуру `card`:
  - `card` - обертка.
  - `card-body` - контент.
  - `card-title` - заголовок объявления.
