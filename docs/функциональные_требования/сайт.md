# Карта сайта и Роутинг проекта «Комок»

Ниже приведено дерево разделов сайта, соответствующее ролям пользователей и требованиям к страницам.

## 1. Публичные страницы (доступны Гостям и Клиентам)
* `/` — **Витрина (Главная страница)**. Список доступных вещей, фильтр по городам, поиск.
* `/item/<int:item_id>` — **Карточка товара**. Подробное описание, характеристики, фотографии, кнопка бронирования.
* `/how-it-works` — **Как это работает**. Статическая страница с описанием правил комиссионного магазина.

---

## 2. Авторизация и профиль
* `/login` — **Авторизация (Вход)**. Форма входа по email или через соцсети. Поддерживает параметр `?next=`.
* `/register` — **Регистрация**. Создание аккаунта с заполнением контактных данных, мессенджеров и реквизитов выплат.
* `/logout` — **Выход из системы**. Сброс сессии и редирект на главную страницу.

---

## 3. Личный кабинет Клиента (Доступен только после авторизации)
Все страницы личного кабинета защищены проверкой авторизации.
* `/cabinet` — **Главная страница ЛК** (или редирект на `/cabinet/bookings`).
* `/cabinet/bookings` — **Мои брони**. Список активных бронирований клиента с возможностью самостоятельной отмены.
* `/cabinet/items/new` — **Продать вещь (Подать заявку)**. Форма предложения вещи с авторасчетом комиссии в реальном времени.
* `/cabinet/items` — **Мои заявки**. История предложенных клиентом вещей и их текущие статусы (`На рассмотрении`, `В продаже`, `Отклонен`, `Продан`).

---

## 4. Панель Администратора (Доступно только пользователям с `is_admin = True`)
Защищено middleware/декоратором проверки прав администратора. При попытке доступа без прав возвращает ошибку `403 Forbidden`.
* `/admin` — **Главная админки** (или редирект на `/admin/pending`).
* `/admin/pending` — **Новые заявки**. Модерация заявок от клиентов: одобрение с коррекцией цены и отклонение.
* `/admin/bookings` — **Активные брони**. Список забронированных товаров, фиксация продажи («Выкуплен») или снятие брони по истечению времени.
* `/admin/items` — **Все товары**. Общая база вещей магазина, возможность отредактировать или удалить любую запись.
