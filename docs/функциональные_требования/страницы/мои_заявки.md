# Мои заявки

## Описание
Страница "Мои заявки" предназначена для управления заявками на размещение товаров, которые пользователь подал на продажу.

## Роли
- Зарегистрированный пользователь (Продавец)

## Функциональные требования
1. **Отображение списка**: Пользователь видит список всех своих поданных заявок.
2. **Информация о заявке**: Статус, данные о товаре, дата подачи, ожидаемая цена.
3. **Отмена заявки**: Пользователь может отменить заявку, если она находится в статусе, позволяющем редактирование (например, до момента перехода в статус "Забронировано" или "Принято на реализацию").
4. **Статусы**:
    - На модерации
    - Ожидание товара
    - В продаже
    - Отклонена
    - Забронировано
    - Продано

## Сценарии использования
- Продавец заходит на страницу "Мои заявки".
- Просматривает текущий статус своих товаров.
- Если товар еще не забронирован, доступна возможность отмены заявки.
- При нажатии на кнопку "Отменить" заявка переходит в статус "Отменена".
