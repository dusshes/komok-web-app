# Страница: Витрина (Главная страница)

Витрина — это главная страница сайта, где гость или авторизованный клиент может ознакомиться со списком продающихся товаров и забронировать их.

## 1. Сетка товаров и UI карточки товара
На странице отображается сетка (grid) карточек активных товаров (у которых статус в БД `items.status = 'available'`).

### Каждая карточка товара должна содержать:
1. **Изображение товара** (если загружено, иначе — заглушка «Нет фото»).
2. **Название** (`items.title`).
3. **Цена** (`items.price` в формате валюты, например, `1 500 руб`).
4. **Город** (`cities.name`), где физически находится товар.
5. **Кнопка «Забронировать»** (логика работы описана в `Роли.md`):
   * Если пользователь Гость — перенаправляем на `/login?next=/book/item_id`.
   * Если пользователь Авторизован — мгновенное бронирование (статус меняется на `booked`, товар пропадает с витрины).

---

## 2. Фильтрация и Поиск
В верхней части страницы расположен блок фильтрации:
* **Фильтр по городам:** 
  * Выпадающий список (выборка городов из таблицы `cities`).
  * Первый пункт списка — **«Все города»** (выбран по умолчанию).
  * При выборе конкретного города отображаются только товары, у которых `items.city_id` совпадает с выбранным.
* **Текстовый поиск:**
  * Поле ввода.
  * Ищет товары по частичному совпадению (без учета регистра) в названии (`items.title`) или описании (`items.description`).
* **Кнопка «Сбросить фильтры»** (появляется, если выбран город или введен текст поиска).

---

## 3. Пагинация (Постраничный вывод)
* На одной странице витрины выводится не более 12 товаров.
* Если товаров больше 12, внизу сетки появляется блок пагинации: кнопки `[Назад]`, `[1]`, `[2]`, `[3]`, `[Вперед]`.
* Смена страниц происходит GET-запросом с параметром `?page=X` (для простоты Flask-архитектуры).

---

## 4. Пустые состояния (Empty States)
* Если в выбранном городе нет товаров или поиск не дал результатов, вместо сетки товаров выводится дружелюбный блок:
  * Текст: `«В этом городе пока нет вещей в продаже. Станьте первым, кто предложит свою вещь!»`
  * Кнопка: `«Продать вещь»` (ведет в личный кабинет на форму подачи заявки).
