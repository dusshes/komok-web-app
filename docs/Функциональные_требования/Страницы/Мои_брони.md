# Мои брони

## Описание
Страница "Мои брони" позволяет пользователю просматривать список своих текущих и завершенных бронирований, а также управлять ими.

## Роли
- Зарегистрированный пользователь (Клиент)

## Функциональные требования
1. **Отображение списка**: Пользователь видит список всех своих бронирований.
2. **Детали бронирования**: Каждая запись содержит информацию о товаре, дате бронирования, статусе и стоимости.
3. **Отмена брони**: Клиент может отменить бронь, если она еще не была выкуплена.
4. **Статусы**:
    - Активна (бронь ожидает выкупа)
    - Выкуплена
    - Отменена

## Сценарии использования
- Пользователь заходит на страницу и видит все свои активные брони.
- Пользователь нажимает кнопку "Отменить" рядом с нужной бронью.
- Система запрашивает подтверждение отмены.
- Статус брони меняется на "Отменена".
