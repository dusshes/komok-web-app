# Технические требования (ТЗ) — Комиссионный магазин «Комок» (v1.0)

## 1. Общие сведения и архитектура
* **Стек:** Python 3.10+, Flask, PostgreSQL, HTML5, CSS3, Vanilla JS.
* **Специфика хостинга (1gb.ru):** Запуск без Docker через веб-сервер Apache + модуль Passenger (WSGI). Память ограничена, код должен быть легковесным.
