# komok-web-app

Веб-приложение для размещения объявлений.

## Начало работы

1.  Клонируйте репозиторий.
2.  Создайте виртуальное окружение: `python -m venv venv`
3.  Активируйте окружение и установите зависимости: `pip install -r requirements.txt`
4.  Создайте файл `.env` на основе примера и укажите необходимые переменные окружения:
    ```
    DATABASE_URL=postgresql+pg8000://user:password@localhost:5432/db_name
    SECRET_KEY=your-secret-key
    RESEND_API_KEY=re_your_api_key_here
    ```
5.  Запустите приложение: `python run.py`

## Особенности
*   Для регистрации требуется обязательное подтверждение email (используется сервис Resend).
*   Приложение использует Flask-WTF для защиты от CSRF-атак.
*   Навигация реализована через общую шапку сайта.
